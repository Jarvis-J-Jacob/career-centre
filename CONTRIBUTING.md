# Contributing

Career Centre welcomes bug reports, synthetic evaluation cases, documentation
improvements and focused pull requests.

## Protect people first

Never submit a real CV, contact detail, work-right record, identity document,
private employer information, account credential or unredacted application
file. Use the synthetic personas and fixtures already in the repository, or
create clearly fictional material.

## Before opening a pull request

1. Describe the user problem and the evidence boundary it affects.
2. Keep provider-neutral behaviour aligned across the ChatGPT and Claude
   packages where applicable.
3. Add or update a synthetic test.
4. Run the skill test suite and repository validator documented in the README.
5. Record any capability, privacy, licence or release-impact change.

Small, reviewable changes are preferred. A job description may define what a
candidate needs, but it must never become evidence that the candidate has done
it.
