# Security and private-data reports

## Supported version

Security fixes apply to the latest published beta or stable release.

## Reporting

Do not include CV content, personal contact details, identity documents,
work-right evidence, private employer material, account cookies, tokens or
login information in a public GitHub issue.

Use GitHub's private security-advisory reporting flow for vulnerabilities. For
ordinary product problems, use the issue form with synthetic or thoroughly
redacted information. If a report cannot be safely redacted, do not publish it
in the issue tracker.

## Scope

Career Centre has no publisher-operated CV database, authentication system or
application-submission service. Its main security boundaries are untrusted CV
and job text, local file handling, generated documents, provider tools,
package integrity and the behaviour of the selected AI host.
